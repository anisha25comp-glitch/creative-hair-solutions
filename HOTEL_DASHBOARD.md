# New website: StayScout Hotel Price Comparison Dashboard

The new Streamlit website is in [`hotel_price_dashboard/`](hotel_price_dashboard/).

Run it with:

```bash
cd hotel_price_dashboard
pip install -r requirements.txt
streamlit run app.py
```

It is an academic prototype using sample/demo hotel data only. It does not scrape MakeMyTrip and does not show live MakeMyTrip prices.
